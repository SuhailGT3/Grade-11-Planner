# 05-01 — Budget method (no totals yet, on purpose)

We do not guess a budget. We build one bottom-up *after* the design is measured, so the number is a
consequence of decisions instead of a wish. Here is the method; fill it in when ready.

## The gate (from the charter)

Before any line below gets a price, these must be true:
- Node table measured ([01-02](../01-research/01-02-measure-and-capture.md)).
- Drawing reviewed by a professional ([03-01](../03-engineering/03-01-safety-review.md)).
- Cut list regenerated and read.

## Step 1 — list everything, then split it

Write two columns. Be ruthless: **Essential** = the kart exists and is safe without it? No → essential.

| Essential (frame stage) | Optional / later |
|---|---|
| Tube (bars from cut list) | Bodywork, livery, number boards |
| Cutting discs, welding consumables | Paint beyond rust primer |
| Seat + belts (only when driving) | Tow bar finish, cosmetic brackets |
| Wheels/tyres, axle, hubs, bearings (when running) | Upgraded wall thickness "just in case" |
| Steering shaft, wheel, joints | |
| Brake kit **or** a documented decision to stay non-powered | |

> "Just in case" upgrades are how budgets die. If a professional says increase a wall, that becomes
> essential; your own speculation does not.

## Step 2 — price three ways and take the honest one

For each essential line, get: (a) new-retail, (b) new-merchant-discount (ask for a *cash* price),
(c) used/offcut. Record all three; choose one and write *why* next to it. The why is as important as
the number for a project you'll defend to a parent or sponsor.

## Step 3 — the sheet format

Keep a simple table (paper or spreadsheet) with columns:
`Item | Qty | Source | New | Used | Chosen | Why | Bought? (date)`.
Update `Bought?` only when money actually moves. The running total at the bottom is the budget.

## Step 4 — contingency

Add **15%** on top of the essential total for the things every first frame discovers (a ruined bar, a
wrong cut, an extra gusset). If you don't spend it, it becomes Project 2 money.

When you complete the sheet, this file gains a second section with the real numbers and the date.
